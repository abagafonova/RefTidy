1. Назначение инструмента

RefTidy — бесплатный браузерный инструмент для создания библиографических записей Zotero из строк цитирования, заметок Obsidian, URL и DOI. Инструмент создаёт файл формата RIS, который можно импортировать в Zotero. Вся обработка выполняется на устройстве пользователя: введённые данные не отправляются на сервер и не покидают браузер. Инструмент создан в исследовательских и образовательных целях и предоставляется «как есть».

Используя инструмент, вы соглашаетесь с настоящими Условиями. Если вы не согласны с каким-либо положением, пожалуйста, воздержитесь от использования.

1. Purpose of the tool

RefTidy is a free browser-based tool for creating Zotero bibliographic records from citation strings, Obsidian notes, URLs, and DOIs. The tool produces a RIS file ready to import into Zotero. All processing runs entirely on your device: the data you enter is never uploaded to a server and never leaves your browser. The tool is provided for research and educational purposes, "as is."
