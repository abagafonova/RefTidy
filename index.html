RefTidy – библиография для Zotero без ручного набора RefTidy – bibliography for Zotero without retyping

Собирает чистую библиографическую карточку из того, что у вас уже есть: строки «Цитировать», ссылки, DOI или заметки Obsidian. На выходе – файл .ris, который Zotero импортирует вместе с правильными выходными данными. Builds a clean bibliographic record from what you already have: citation strings, links, DOIs, or Obsidian notes. The output is a .ris file that Zotero imports with the publication details intact.

Загрузить библиографию списком Load bibliography as a list

Для случая, когда записей сотни: список литературы из диссертации, статьи или курсовой. Разбирает оформление по ГОСТ 7.1 – книги, статьи, главы в сборниках, диссертации, архивные дела. Заголовки разделов распознаются и переносятся в Zotero метками, так что структура списка не теряется. For when you have hundreds of entries: the reference list from a dissertation, article, or term paper. Parses GOST 7.1 formatting – books, articles, book chapters, dissertations, archival files. Section headings are recognised and transferred to Zotero as tags, so the list structure is preserved.

Пользуетесь Obsidian? Using Obsidian?

Obsidian – редактор заметок, в который удобно сохранять статьи прямо из браузера расширением Web Clipper. Здесь это один из способов ввода, а не обязательное условие: всё остальное работает и без него. Obsidian is a note-taking app; its Web Clipper extension saves publications straight from the browser. Here it is simply one way to supply a source – everything else works without it.

Готовый шаблон клиппера складывает выходные данные публикации в свойства заметки и дублирует их в её текст. Тогда карточка собирается из метаданных страницы, а не из разбора её текста, – и выходит точнее. The ready-made clipper template writes the publication’s metadata into the note’s properties and repeats it in the note body. The record is then built from the page’s own metadata rather than from parsing its text, which is more accurate.

В Obsidian Web Clipper: шестерёнка → Templates → импорт файла. In Obsidian Web Clipper: gear icon → Templates → import the file.

  1. Через файл: «Скачать .ris» → в Zotero меню Файл → Импорт… → укажите скачанный файл. Via file: "Download .ris" → in Zotero menu File → Import… → select the downloaded file.
  2. Через буфер: «Копировать RIS» → в Zotero меню Файл → Импорт из буфера обмена. Via clipboard: "Copy RIS" → in Zotero menu File → Import from Clipboard.
  3. Перетащите свою .md-заметку мышкой на появившуюся в Zotero карточку – она прикрепится как вложение. Drag your .md note onto the newly created Zotero entry – it will attach as a file.
